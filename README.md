# DevOps with Kubernetes Course Exercise Repository

This repository contains the exercises submitted for the course **DevOps with Kubernetes 2024**.

## Structure

- **Exercise Folders**: Each exercise is in a numbered folder (e.g., `Part4/4.01`). Inside, you'll find the full application, commands used, and relevant information in the `README.md`.
  
- **Legacy Exercises**: If a folder contains only a `README.md`, the code was developed in an earlier exercise. The `README.md` will direct you to the correct location, and if not, just check a couple of the previous folders.

## Notes

The repository has some redundancy due to my initial approach of copying entire applications for each exercise. This was useful for quick reference but led to some messiness. Using Git more effectively could have streamlined this process.
